# 🌸 La Belle Bouquet — Melbourne Luxury Florist & Hampers

A boutique, responsive website for **La Belle Bouquet** (`@labellebouquett`), Melbourne. Inspired by the clean floral aesthetic of [The Flower Shed](https://www.theflowershed.com.au/), built with pure HTML5, modern CSS3, and vanilla JavaScript.

---

## ✨ Features

- **Melbourne Same-Day Delivery**: Top announcement bar highlighting Melbourne cut-off times (orders before 1:00 PM) and local courier delivery coverage.
- **Authentic Instagram Catalog**: 8 handcrafted flower bouquets, rose & bunny keepsake baskets, and luxury designer hampers (Dior, Burberry, YSL) sourced directly from `@labellebouquett`.
- **Interactive "Buy Now" Order Flow**: Clicking "Buy Now" on any card pre-selects the item, calculates prices dynamically, and smoothly scrolls to the custom order inquiry form.
- **Customizable Bouquet Tiers & Add-ons**:
  - Size tiers: *Classic Standard*, *Deluxe Fullness (+25% Roses)*, *Grand Luxe Opulence (+50% Blooms)*.
  - Luxury add-ons: *Ferrero Rocher Truffles*, *Plush Companion Bunny*, *Satin Ribbon & Wax Seal*.
- **Real-Time Handwritten Card Preview**: A live calligraphy mirror rendered on textured luxury paper as the customer types their personal card message.
- **Direct Email & Instagram Ordering**:
  - Automatically composes order inquiry emails to **`hello.labellebouquet@gmail.com`**.
  - Displays an on-screen Order Confirmation modal with one-click clipboard copying.
  - One-click direct link to send the order via **Instagram DM to [@labellebouquett](https://www.instagram.com/labellebouquett/)**.
- **Delivery FAQ & Care Guide**: Accordion detailing Melbourne delivery suburbs, same-day cutoffs, hydration packs, and custom perfume preferences.

## 🚀 How to Run & Host

### Local Preview
Simply open `index.html` in any web browser:
```powershell
Start-Process index.html
```

### Free 1-Click Hosting on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages** in your repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Set branch to `main` and folder to `/ (root)`.
5. Click **Save**. Within 1–2 minutes, your website will be live at `https://<your-username>.github.io/<repo-name>/`!
